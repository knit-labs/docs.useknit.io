#### Get Supported Networks

<div style={{ display: "flex", alignItems: "center" }}>
  ##### Endpoint
  <span
    style={{

  >
    GET
  </span>
</div>

```js copy
{{baseUrl}}/api/v1/networks
```

##### Headers

- X-API-KEY: Your API key **or** use `Authorization: Bearer <token>` with an
  OAuth access token.
- Accept: Set to application/json to receive the response in JSON format.

##### Sample Request

```js copy filename="Sample Request"
curl --location -g '{{baseUrl}}/api/v1/networks' \
--header 'X-API-KEY: {{apiKey}}' \
--header 'Accept: application/json'
```
