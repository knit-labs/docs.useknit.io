# List payouts

Returns the payouts belonging to your business.

<Endpoint method="GET" path="/api/v1/payouts" />

<Meta>
  <Scope value="payouts:read" />
  <Chip label="Auth" value="Bearer token" />
</Meta>

## Request

```bash filename="cURL"
curl "https://api-prod.useknit.io/api/v1/payouts" \
  -H "Authorization: Bearer $KNIT_ACCESS_TOKEN" \
  -H "Accept: application/json"
```

  that stays stable across your own retries.
</Callout>

## Errors

| Status | Cause |
| ------ | ----- |
| `401` | Missing or invalid token, IP not allow-listed, or missing `payouts:read` |
