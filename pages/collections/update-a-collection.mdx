# Update a collection

Amends a collection that has not yet been paid. Send only the fields you want
to change.

<Endpoint method="PUT" path="/api/v1/collections/{id}" />

<Meta>
  <Scope value="collections:write" />
  <Chip label="Auth" value="Bearer token" />
</Meta>

<Callout type="warning">
  Updating does not extend the 30-minute expiry and does not issue a new
  address. Once a payment has been detected, create a new collection instead of
  amending this one.
</Callout>

## Path parameters

<Fields>
  <Field name="id" type="string" required>
    The collection's `id`.
  </Field>
</Fields>

## Body

Every field is optional; omitted fields are left unchanged.

<Fields>
  <Field name="network" type="string" required={false}>
    A network that is active for collections.
  </Field>
  <Field name="token" type="string" required={false}>
    A token that is active for collections on that network.
  </Field>
  <Field name="tokenAmount" type="number" required={false}>
    Must be greater than zero.
  </Field>
  <Field name="confirmationThreshold" type="integer" required={false}>
    Must be greater than zero.
  </Field>
  <Field name="merchantCallbackUrl" type="string" required={false}>
    Must be a publicly reachable `http://` or `https://` URL.
  </Field>
  <Field name="merchantRedirectUrl" type="string" required={false}>
    Must be a valid `http://` or `https://` URL, or `null` to clear it.
  </Field>
</Fields>

## Request

```bash filename="cURL"
curl -X PUT "https://api-prod.useknit.io/api/v1/collections/9cddd3ad-c2a8-463c-a703-158b900beea8" \
  -H "Authorization: Bearer $KNIT_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "tokenAmount": 3000,
    "merchantRedirectUrl": "https://example.com/checkout/complete"
  }'
```

## Errors

| Status | Cause |
| ------ | ----- |
| `401` | Missing or invalid token, IP not allow-listed, or missing `collections:write` |
| `404` | No collection with that ID belongs to your business |
| `400` | A supplied field failed validation |
