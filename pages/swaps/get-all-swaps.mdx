# List swaps

Returns the swaps of your business, newest first. The list is paginated. Pass
`merchantReference` to find the swap you created with that reference.

<Endpoint method="GET" path="/api/v1/swaps" />

<Meta>
  <Scope value="swaps:read" />
  <Chip label="Auth" value="Bearer token" />
</Meta>

## Query parameters

<Fields>
  <Field name="merchantReference" type="string" required={false}>
    Only the swap you created with this `merchantReference`. The list has one
    item if that swap exists, and is empty if it does not. Maximum 255
    characters. If you send the parameter, it must not be empty.
  </Field>
  <Field name="fromToken" type="string" required={false}>
    Only swaps that paid with this token, for example `USDT`.
  </Field>
  <Field name="toToken" type="string" required={false}>
    Only swaps that got this token, for example `ETH`.
  </Field>
  <Field name="from" type="string" required={false}>
    Only swaps created at or after this time. An ISO 8601 date or date and
    time, for example `2026-11-01T00:00:00Z`. A time without an offset is read
    as UTC.
  </Field>
  <Field name="to" type="string" required={false}>
    Only swaps created before this time. Must be later than `from`.
  </Field>
  <Field name="page" type="integer" required={false} defaultValue="1">
    The page to fetch. Minimum `1`, maximum `10000`.
  </Field>
  <Field name="perPage" type="integer" required={false} defaultValue="15">
    Swaps per page. Minimum `1`, maximum `100`.
  </Field>
</Fields>

## Request

```bash filename="cURL"
curl -G "https://api-prod.useknit.io/api/v1/swaps" \
  -H "Authorization: Bearer $KNIT_ACCESS_TOKEN" \
  -H "Accept: application/json" \
  --data-urlencode "merchantReference=swap-001"
```

## Errors

| Status | Cause |
| ------ | ----- |
| `400` | A query parameter is not valid, for example an empty `merchantReference`, `perPage` above `100` or `to` before `from`. The body carries an `errors` entry for the parameter |
| `401` | Missing or invalid token, IP not allow-listed, or missing `swaps:read` |
| `403` | API Services are not enabled for your business |
