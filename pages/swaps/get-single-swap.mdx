# Retrieve a swap

Returns one swap of your business.

<Endpoint method="GET" path="/api/v1/swaps/{id}" />

<Meta>
  <Scope value="swaps:read" />
  <Chip label="Auth" value="Bearer token" />
</Meta>

## Path parameters

<Fields>
  <Field name="id" type="string" required>
    The `id` from the [Create a swap](/swaps/create-a-swap) response.
  </Field>
</Fields>

## Request

```bash filename="cURL"
curl "https://api-prod.useknit.io/api/v1/swaps/e2a4f6b8-1c3d-4e5f-8a9b-0c1d2e3f4a5b" \
  -H "Authorization: Bearer $KNIT_ACCESS_TOKEN" \
  -H "Accept: application/json"
```

## Errors

| Status | Cause |
| ------ | ----- |
| `401` | Missing or invalid token, IP not allow-listed, or missing `swaps:read` |
| `403` | API Services are not enabled for your business |
| `404` | `Swap not found`: no swap of your business has this `id` |
