# Update a wallet

Amends an existing API wallet. Send only the fields you want to change. Use
`networks` to let an EVM wallet receive deposits on more EVM networks.

<Endpoint method="PUT" path="/api/v1/wallets/{id}" />

<Meta>
  <Scope value="wallets:write" />
  <Chip label="Auth" value="Bearer token" />
</Meta>

## Adding networks

- **The address stays the same.** One EVM address works on every EVM network,
  so your customers keep using the address they already have.
- **Networks are only added.** Knit adds the networks you send to the ones the
  wallet already has. A network that you leave out of the request stays on the
  wallet. You cannot remove a network.
- **EVM wallets only.** You can add `MATIC_MAINNET`, `MATIC_AMOY`,
  `BSC_MAINNET`, `ETHEREUM_MAINNET` and `BASE_MAINNET`. A Tron wallet cannot
  take EVM networks.

<Callout type="warning">
  Knit starts to watch an added network when the update succeeds. Knit may
  not detect a deposit made on that network before the update. Add the
  network before your customer sends funds on it.
</Callout>

## Path parameters

<Fields>
  <Field name="id" type="string" required>
    The wallet's `id`.
  </Field>
</Fields>

## Body

<Fields>
  <Field name="networks" type="string[]" required={false}>
    EVM network identifiers to add to the wallet. Must contain at least one
    entry. Networks the wallet already has are kept, so you can send only the
    new ones or the full list.
  </Field>
  <Field name="network" type="string" required={false}>
    The wallet's primary network identifier. Changing it does not add a
    network. Use `networks` for that. When you send both, `network` must be one
    of the wallet's networks after the update.
  </Field>
  <Field name="type" type="string" required={false}>
    The wallet's type classification.
  </Field>
</Fields>

## Request

```bash filename="Add Base and BNB Smart Chain"
curl -X PUT "https://api-prod.useknit.io/api/v1/wallets/d95143d2-c076-49da-b121-b3beed054bf3" \
  -H "Authorization: Bearer $KNIT_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "networks": ["BASE_MAINNET", "BSC_MAINNET"] }'
```

## Response

The wallet was on Polygon only. After the update, the same address receives
deposits on Polygon, Base and BNB Smart Chain.

## Errors

| Status | Cause |
| ------ | ----- |
| `401` | Missing or invalid token, IP not allow-listed, or missing `wallets:write` |
| `404` | No wallet with that ID belongs to your business |
| `400` | A supplied field failed validation, `networks` holds a network that is not EVM, or the wallet is a Tron wallet |
| `409` | Another request is adding networks to this wallet. Try again |
