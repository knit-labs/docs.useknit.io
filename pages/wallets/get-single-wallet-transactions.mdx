# List wallet transactions

Returns the transactions recorded against one API wallet, with filtering and
pagination.

<Endpoint method="GET" path="/api/v1/wallets/{id}/transactions" />

<Meta>
  <Scope value="wallets:read" />
  <Chip label="Auth" value="Bearer token" />
</Meta>

## Path parameters

<Fields>
  <Field name="id" type="string" required>
    The wallet's `id`.
  </Field>
</Fields>

## Query parameters

<Fields>
  <Field name="page" type="integer" required={false} defaultValue="1">
    The page to fetch. Minimum `1`.
  </Field>
  <Field name="perPage" type="integer" required={false} defaultValue="10">
    Items per page. Minimum `1`, maximum `100`.
  </Field>
  <Field name="network" type="string" required={false}>
    Filter to one network identifier.
  </Field>
  <Field name="token" type="string" required={false}>
    Filter to one token symbol.
  </Field>
  <Field name="status" type="string" required={false}>
    Filter to one transaction status, for example `SUCCESSFUL`.
  </Field>
  <Field name="dateFrom" type="date" required={false}>
    Only transactions on or after this date.
  </Field>
  <Field name="dateTo" type="date" required={false}>
    Only transactions on or before this date. Must not be earlier than
    `dateFrom`.
  </Field>
</Fields>

## Request

```bash filename="cURL"
curl -G "https://api-prod.useknit.io/api/v1/wallets/d95143d2-c076-49da-b121-b3beed054bf3/transactions" \
  -H "Authorization: Bearer $KNIT_ACCESS_TOKEN" \
  -H "Accept: application/json" \
  --data-urlencode "status=SUCCESSFUL" \
  --data-urlencode "perPage=25" \
  --data-urlencode "page=1"
```

## Errors

| Status | Cause |
| ------ | ----- |
| `401` | Missing or invalid token, IP not allow-listed, or missing `wallets:read` |
| `422` | `perPage` is above 100, or `dateTo` is earlier than `dateFrom` |
