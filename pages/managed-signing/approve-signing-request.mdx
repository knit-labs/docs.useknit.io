```js copy
{{baseUrl}}/api/v1/managed-signing/requests/{requestId}/approve
```

This endpoint approves a pending signing request.

##### Headers

- `X-API-KEY`: Your API key for authentication.
- `Accept`: Set to `application/json` to receive responses in JSON format.

##### Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `requestId` | string | Yes | The local request ID |

##### Sample Request

```sh copy
curl --location -g --request POST '{{baseUrl}}/api/v1/managed-signing/requests/<local-request-id>/approve' \
--header 'X-API-KEY: {{apiKey}}' \
--header 'Accept: application/json'
```

##### Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Local request ID |
| `businessId` | string | Your business ID |
| `walletId` | string | Local wallet ID |
| `network` | string | Target network |
| `type` | string | Request type |
| `kind` | string | Transaction kind |
| `status` | string | Request status (updated to `SIGNED`) |
| `payload` | object | Request payload |
| `signature` | string | Generated signature |
| `broadcast` | boolean | Broadcast flag |
| `createdAt` | string | Creation timestamp |
| `updatedAt` | string | Last update timestamp |

##### Notes

- Only requests with status `AWAITING_APPROVAL` can be approved.
- After approval, the status changes to `SIGNED`.
- If `broadcast` was set to `true` during creation, the transaction will be broadcast after signing.
