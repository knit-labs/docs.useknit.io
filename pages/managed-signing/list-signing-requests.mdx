# List Signing Requests

<Endpoint method="GET" path="/api/v1/managed-signing/requests" />

<Meta>
  <Scope value="managed-signing:read" />
  <Chip label="Auth" value="Bearer token" />
</Meta>

This endpoint retrieves all signing requests for your business with optional filtering.

## Query Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `walletId` | string | No | Filter by local wallet ID |
| `status` | string | No | Filter by status |

## Available Status Values

- `AWAITING_APPROVAL`
- `SIGNED`
- `POLICY_DENIED`
- `FAILED`

## Request

```bash
curl "https://api-prod.useknit.io/api/v1/managed-signing/requests?walletId=<local-wallet-id>&status=SIGNED" \
  -H "Authorization: Bearer $KNIT_ACCESS_TOKEN" \
  -H "Accept: application/json"
```

## Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Local request ID |
| `businessId` | string | Your business ID |
| `walletId` | string | Local wallet ID |
| `network` | string | Target network |
| `type` | string | Request type |
| `kind` | string | Transaction kind |
| `status` | string | Request status |
| `payload` | object | Request payload |
| `signature` | string | Generated signature (if signed) |
| `broadcast` | boolean | Broadcast flag |
| `createdAt` | string | Creation timestamp |
| `updatedAt` | string | Last update timestamp |
