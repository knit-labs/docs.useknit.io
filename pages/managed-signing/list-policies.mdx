# List Policies

<Endpoint method="GET" path="/api/v1/managed-signing/policies" />

<Meta>
  <Scope value="managed-signing:read" />
  <Chip label="Auth" value="Bearer token" />
</Meta>

This endpoint retrieves all policies for your business.

## Request

```bash
curl "https://api-prod.useknit.io/api/v1/managed-signing/policies" \
  -H "Authorization: Bearer $KNIT_ACCESS_TOKEN" \
  -H "Accept: application/json"
```

## Response

```json filename="Response"
{
  "statusCode": 200,
  "message": "Policies retrieved",
  "data": [
    {
      "id": "<local-policy-id>",
      "businessId": "<business-id>",
      "name": "default",
      "rules": {
        "chains": ["ETHEREUM_MAINNET"],
        "maxApprovalAmount": "1000000",
        "denyUnlimitedApprovals": true
      },
      "createdAt": "2026-01-20T18:30:40.912Z",
      "updatedAt": "2026-01-20T18:30:40.912Z"
    }
  ],
  "success": true
}
```

## Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | string | Local policy ID |
| `businessId` | string | Your business ID |
| `name` | string | Policy name |
| `rules` | object | Policy rules configuration |
| `createdAt` | string | Creation timestamp |
| `updatedAt` | string | Last update timestamp |
