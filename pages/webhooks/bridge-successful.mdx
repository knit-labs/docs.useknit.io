# `BRIDGE_SUCCESSFUL`

Delivered when a [bridge](/API-account/create-a-bridge) is complete: your
[network liquidity](/API-account/get-network-liquidity) (the funds Knit holds for
your payouts on a network) went down on one network and went up on the other.
Use it to update your ledger.

<Meta>
  <Chip label="Envelope" value="body wrapper" />
  <Chip label="Keys" value="camelCase" />
</Meta>

Delivered to your business webhook URL.

<Callout type="info">
  A bridge is complete when Knit answers your create request, so the response
  already tells you the outcome. This event is the record for systems that
  listen for webhooks instead. A bridge that Knit refuses is not created and
  produces no event.
</Callout>

## Payload

`bridge` has the same fields as the
[Create a bridge](/API-account/create-a-bridge#response) response.

```json filename="BRIDGE_SUCCESSFUL"
{
  "body": {
    "eventType": "BRIDGE_SUCCESSFUL",
    "bridge": {
      "id": "9f3c2a71-5d0e-4b8a-9a43-6c2f1e7b8d10",
      "merchantReference": "rebalance-001",
      "token": "USDT",
      "fromNetwork": "TRON_MAINNET",
      "toNetwork": "ETHEREUM_MAINNET",
      "amount": "200",
      "fee": "2",
      "feesBreakdown": [
        { "type": "PROVIDER", "amount": "1.2" },
        { "type": "NETWORK", "amount": "0.6" },
        { "type": "KNIT", "amount": "0.2" }
      ],
      "totalDebit": "202",
      "accountBalanceBefore": "500",
      "accountBalanceAfter": "498",
      "status": "SUCCESSFUL",
      "createdAt": "2026-11-21T23:10:04.000000Z"
    }
  }
}
```

## Handling

<Steps>

### Verify and acknowledge

Check `X-Signature` against the raw body, then return `2xx` straight away. See
[Webhooks](/webhooks) for the verification snippet.

### Deduplicate on `merchantReference`

`merchantReference` is the value you sent when you created the bridge. Check
whether you have already recorded it before doing anything else: this event
can arrive more than once, and you may have recorded the bridge from the create
response already.

### Record

Record `totalDebit` leaving `fromNetwork` and `amount` arriving on
`toNetwork`. Your API account balance for `token` goes down by `fee` only:
`accountBalanceBefore` and `accountBalanceAfter` let you check your ledger
against Knit's.

</Steps>

## Not receiving it?

- Confirm the webhook URL and secret in **Business → Developer → Webhooks**,
  and that the endpoint is publicly reachable.
- Check the delivery attempts in the dashboard. A `4xx` from your endpoint is
  recorded there along with the response body.
- Remember the retry window is about 24 hours. Past that, reconcile with
  [Get all bridges](/API-account/get-all-bridges).
